# Canonical Experiment Pipeline

This document describes the single, authoritative workflow for reproducing all experimental results in this project.

---

## Pipeline Overview

```
┌─────────────────┐     ┌──────────────────────┐     ┌──────────────────┐
│ 1. Run Experiment   │     │ 2. Analyze Results     │     │ 3. Generate Paper  │
│    Main.java    ───▶│     │    analyze.py       ───▶│    Tables/Figs    │
└─────────────────┘     └──────────────────────┘     └──────────────────┘
        │                        │                          │
        ▼                        ▼                          ▼
results/full_experiment.csv   tables/*.tex              Paper draft
         2250 rows              figures/*.png              LaTeX tables
```

---

## Step 1: Run the Experiment

### Using the build script (recommended)

```bash
# Default parameters: n={20,50,100,200,500}, W=1000, instances=30, seed=42
./build_and_run.sh

# Custom parameters
./build_and_run.sh 20,50,100,200,500 1000 30 42
```

### Using Maven

```bash
mvn clean compile exec:java -Dexec.mainClass=Main -Dexec.args="20,50,100,200,500 1000 30 42"
```

### Using Java directly (after mvn package)

```bash
java -jar target/knapsack-comparison-1.0-SNAPSHOT.jar 20,50,100,200,500 1000 30 42
```

### Output

- **File**: `results/full_experiment.csv` (canonical CSV, 2250 rows = 750 instances × 3 algorithms)
- **Columns**: algorithm, dataset_type, n, capacity, instance_id, seed, time_nanos, time_millis, memory_bytes, memory_mb, solution_value, optimal_value, optimality_gap, nodes_explored, optimal

---

## Step 2: Run Canonical Analysis

### Prerequisites

- Python 3.8+ (standard library only - no external dependencies)

```bash
python3 analyze.py results/full_experiment.csv
```

### Output

- **LaTeX Tables**: `tables/table_*.tex` (copy directly into paper)
- **CSV Summary**: `tables/table_full_summary.csv`
- **Text Summary**: Printed to stdout

### Generated Tables

| File | Description |
|------|-------------|
| `table_time_n500.tex` | Mean execution time at n=500 with 95% CI |
| `table_greedy_gap.tex` | Greedy optimality gap with median, mean±std, 95% CI |
| `table_bb_nodes.tex` | B&B nodes explored (median, 95% CI, min, max) |
| `table_bb_time_n500.tex` | B&B time at n=500 with outlier analysis |
| `table_dp_scaling.tex` | DP time by n and family (95% CI) |
| `table_full_summary.csv` | Complete summary (all n, all algorithms, all families) |

---

## Step 3: Use in Paper

1. Copy `tables/*.tex` into your paper's LaTeX source
2. Include with `\input{tables/table_time_n500}` etc.
3. All numerical claims in paper MUST come from these tables

## Provenance Chain

Every paper number traces to:

```
Paper Table/Figure
      │
      ▼
tables/*.tex (generated by analyze.py)
      │
      ▼
analyze.py (reads CSV, computes statistics)
      │
      ▼
results/full_experiment.csv (2250 rows)
      │
      ▼
Main.java → BenchmarkRunner → Algorithms
      │
      ▼
DatasetGenerator (5 families × 5 sizes × 30 seeds = 750 instances)
```

**No manual editing of numbers.** If a number changes, re-run the pipeline.

## Troubleshooting

### "NoClassDefFoundError: org/apache/commons/csv/CSVPrinter"
The build script handles classpath. Run from project root:
```bash
./build_and_run.sh
```

### "ModuleNotFoundError: pandas/matplotlib"
The analysis script uses only Python standard library. No external packages needed.

### Experiment takes too long
Reduce instances or sizes:
```bash
./build_and_run.sh 20,50,100 1000 10 42
```

### Want to use Maven JAR
```bash
mvn clean package
java -jar target/knapsack-comparison-1.0-SNAPSHOT.jar 20,50,100,200,500 1000 30 42
```
