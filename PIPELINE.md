# Canonical Experiment Pipeline

This document describes the single, authoritative workflow for reproducing all experimental results in this project.

---

## Pipeline Overview

```
┌─────────────────┐     ┌──────────────────────┐     ┌──────────────────┐
│ 1. Run Experiment   │     │ 2. Analyze Results     │     │ 3. Generate Paper  │
│    Main.java    ───▶│     │    analyze.py       ───▶│    Tables/Figs    │
└─────────────────┘     └──────────────────────┘     └──────────────────┘
        │                        │                          │
        ▼                        ▼                          ▼
out/results/               tables/*.tex              Paper draft
  full_experiment.csv      figures/fixed/pdf/*.pdf    LaTeX tables
          18000 rows        figures/scaled/pdf/*.pdf
```

---

## Step 1: Run the Experiment

### Using the build script (recommended)

```bash
# Default parameters: n={20,50,100,200,500}, capacity=1000, instances=30, seed=42
# Note: reproduce.sh runs with n up to 1000 and 100 seeds for both fixed and scaled capacity.
./build_and_run.sh

# Custom parameters
./build_and_run.sh 20,50,100,200,500 1000 30 42
```

### Using Maven

```bash
mvn clean package -q
java -jar target/knapsack-comparison-2.0.0.jar 20,50,100,200,500 1000 30 42
```

### Using Java directly (after mvn package)

```bash
java -jar target/knapsack-comparison-2.0.0.jar 20,50,100,200,500 1000 30 42
```

### Output

- **File**: `out/results/full_experiment.csv` (canonical CSV, 18000 rows = 3000 instances x 3 algorithms x 2 modes)
- **Columns**: algorithm, dataset_type, n, capacity, instance_id, seed, time_nanos, time_millis, memory_bytes, memory_mb, solution_value, optimal_value, optimality_gap, nodes_explored, nodes_pruned, max_queue_size, optimal, capacity_mode

---

## Step 2: Run Canonical Analysis

### Prerequisites

- Python 3.8+ with numpy and matplotlib

```bash
python3 analyze.py out/results/full_experiment.csv
```

### Output

- **LaTeX Tables**: `tables/*_table_*.tex` (copy directly into paper, `fixed_` and `scaled_` variants)
- **CSV Summary**: `tables/*_table_full_summary.csv`
- **Text Summary**: Printed to stdout
- **Figures**: `figures/fixed/pdf/*.pdf`, `figures/fixed/png/*.png`, `figures/fixed/svg/*.svg` and `figures/scaled/pdf/*.pdf`, `figures/scaled/png/*.png`, `figures/scaled/svg/*.svg`

### Generated Tables (per capacity mode: `fixed_` and `scaled_` prefix)

| File | Description |
|------|-------------|
| `{mode}_table_time_max_n.tex` | Mean execution time at n=1000 with 95% CI |
| `{mode}_table_greedy_gap.tex` | Greedy optimality gap with median, mean +/- std, 95% CI |
| `{mode}_table_bb_nodes.tex` | B&B nodes explored (median, 95% CI, min, max) |
| `{mode}_table_bb_time.tex` | B&B time at n=1000 with outlier analysis |
| `{mode}_table_dp_scaling.tex` | DP time by n and family (95% CI) |
| `{mode}_table_bb_pruning.tex` | B&B pruning analysis (median explored, pruned, pruning %) |
| `{mode}_table_full_summary.csv` | Complete summary (all n, all algorithms, all families) |

---

## Step 3: Use in Paper

1. Copy `tables/*.tex` into your paper's LaTeX source
2. Include with `\input{tables/fixed_table_time_max_n}` or `\input{tables/scaled_table_time_max_n}` etc.
3. All numerical claims in paper MUST come from these tables

## Canonical Files (Do Not Modify)

| File | Purpose |
|------|---------|
| `src/main/java/Main.java` | **Only** experiment entry point |
| `build_and_run.sh` | Build + run wrapper |
| `analyze.py` | **Only** analysis script (requires numpy, matplotlib) |
| `pom.xml` | Maven config (mainClass=Main) |
| `out/results/full_experiment.csv` | Canonical experiment output |
| `tables/*.tex` | Canonical paper tables |

> **Developer utilities** (not part of the reproduction pipeline):
> - `update_draft.py` — Synchronizes `paper/draft.md` with current experiment parameters and replaces inline tables with `\input{}` directives. Run after `./reproduce.sh` to refresh the paper draft.

## Provenance Chain

Every paper number traces to:

```
Paper Table/Figure
      |
      v
tables/*.tex (generated by analyze.py)
      |
      v
analyze.py (reads CSV, computes statistics, generates figures)
      |
      v
out/results/full_experiment.csv (18000 rows)
      |
      v
Main.java -> BenchmarkRunner -> Algorithms
      |
      v
DatasetGenerator (5 families x 6 sizes x 100 seeds = 3000 instances per mode)
```

**No manual editing of numbers.** If a number changes, re-run the pipeline.

## Parameters (Fixed for Reproducibility)

| Parameter | Value |
|-----------|-------|
| Instance families | 5 (Uncorrelated, WeaklyCorrelated, StronglyCorrelated, InverseCorrelated, AlmostEqualRatios) |
| Problem sizes (n) | 20, 50, 100, 200, 500, 1000 |
| Capacity (W) | 1000 (fixed) and 0.5 * sum(weights) (scaled) |
| Seeds per (n, family) | 100 |
| Total instances | 3,000 per mode (6,000 total) |
| Algorithms | 3 (Greedy, DP, B&B) |
| Total runs | 18,000 |
| Warmup runs | 1 (per-instance) + 10k global JIT iterations per (n, family) |
| Timeout | 30 seconds |
| Random seed | 42 |

## Troubleshooting

### "NoClassDefFoundError: org/apache/commons/csv/CSVPrinter"
The build script handles classpath. Run from project root:
```bash
./build_and_run.sh
```

### "ModuleNotFoundError: numpy" or "ModuleNotFoundError: matplotlib"
The analysis script requires numpy and matplotlib. Install with: `pip install numpy matplotlib`

### Experiment takes too long
Reduce instances or sizes:
```bash
./build_and_run.sh 20,50,100 1000 10 42
```

### Want to use Maven JAR
```bash
mvn clean package
java -jar target/knapsack-comparison-2.0.0.jar 20,50,100,200,500 1000 30 42
```
